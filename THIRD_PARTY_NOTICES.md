# Third-party notices

## Code included in WhatClip
None. Every source file in `Sources/` and `Tests/` was written for this project. WhatClip has no package dependencies.

## Frameworks used (Apple, part of macOS and the Command Line Tools)
AppKit, Foundation, SwiftUI-free UI on AppKit, CryptoKit, Vision, ScreenCaptureKit, ImageIO, Quick Look, Carbon (hot-key API), LocalAuthentication, ServiceManagement, Security (Keychain), UniformTypeIdentifiers, SQLite3 (the system library). These belong to Apple and are used under Apple's terms.
